# TODOApp

検索機能付きのシンプルなTODOアプリです。ビルドや依存関係は不要で、`index.html` をブラウザで開くだけで動作します。

## 機能

- **TODO管理**: 追加・完了チェック・削除
- **編集**: 「編集」ボタン、または文字をダブルクリックでインライン編集
  - `Enter` で確定 / `Esc` でキャンセル / 入力欄の外をクリックしても確定
  - 空にして確定した場合は元の内容のまま
- **検索**: キーワードによる部分一致検索
  - 大文字小文字を区別しない(全角・半角の違いも同一視)
  - 入力に合わせてリアルタイムに絞り込み(日本語入力の変換中も更新)
  - 一致箇所のハイライトと件数表示
- **保存**: ブラウザの `localStorage` に自動保存(リロードしても残ります)
- **ダークモード**: OS の設定に自動で追従

## 使い方

```
git clone https://github.com/qsarkbir/TODOApp.git
```

クローン後、`index.html` をブラウザで開いてください。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | HTML・CSS・JavaScript をまとめた単一ファイルのアプリ本体 |

## 注意

- データは利用しているブラウザ内にのみ保存されます。別のブラウザや端末とは共有されません。
- ブラウザのサイトデータを削除すると、TODOも消えます。
